# CRM Stages Manager - Joomla + PHP + Docker

## 🚀 Быстрый старт

### Требования
- Docker Desktop установлен и запущен
- Порты 8080, 8081, 3306 свободны

### Запуск (1 команда)

**Linux/Mac:**
```bash
chmod +x start.sh && ./start.sh
```

**Windows:**
```cmd
start.bat
```

**Или вручную:**
```bash
docker-compose up -d
```

### Подождите 30-60 секунд

MySQL инициализируется при первом запуске. Это нормально, что он показывает ошибку в начале - через минуту всё заработает.

### Откройте в браузере

| URL | Описание |
|-----|----------|
| **http://localhost:8080/crm-api.php** | 🚀 CRM Interface |
| http://localhost:8080/setup-crm.php | ⚙️ Проверка установки |
| http://localhost:8081 | 📊 phpMyAdmin |

## 🎯 Функциональность

### Карточка компании включает:
- ✅ Текущую стадию с визуальным прогресс-баром
- ✅ Список доступных действий (с учётом ограничений)
- ✅ Блок "Инструкция/скрипт" для менеджера
- ✅ Историю событий компании
- ✅ Данные Discovery (если заполнены)
- ✅ Контактную информацию

### Стадии воронки:
```
C0 (Ice) → C1 (Touched) → C2 (Aware) → W1 (Interested) → 
W2 (Demo Planned) → W3 (Demo Done) → H1 (Committed) → 
H2 (Customer) → A1 (Activated)
```

### Ограничения по стадиям:

| Стадия | Запрещено | Условие входа | Условие выхода |
|--------|-----------|---------------|----------------|
| C0 Ice | Заявка, КП, демо | - | Разговор с ЛПР |
| C1 Touched | Заявка, КП, демо | Разговор с ЛПР | Discovery заполнен |
| W1 Interested | Заявка, КП | Discovery заполнен | Демо запланировано |
| W2 Demo Planned | Заявка, КП | Демо запланировано | Демо проведено |
| W3 Demo Done | - | Демо < 60 дней | Счёт выставлен |
| H1 Committed | - | Счёт выставлен | Оплата получена |
| H2 Customer | - | Оплата получена | Удостоверение выдано |
| A1 Activated | - | Удостоверение выдано | Финал |

## 🗄️ Модель данных

### Таблицы:

```sql
crm_companies      -- Компании
crm_events         -- Event Sourcing (все события)
crm_stage_transitions -- Лог переходов между стадиями
crm_discovery      -- Данные Discovery-формы
crm_demos          -- Запланированные/проведённые демо
crm_invoices       -- Счета
crm_certificates   -- Удостоверения
```

### Ключевые индексы:
```sql
idx_company_stage        -- Быстрый поиск по стадии
idx_events_company_date  -- Составной индекс для истории
idx_transitions_company  -- Для аудита переходов
idx_demos_company_status -- Для проверки условий
```

## 🧪 Тестирование

Нажмите кнопку **"🧪 Тесты"** в интерфейсе для запуска unit-тестов.

### Покрытые сценарии:
1. Ice: fill_discovery недоступен (нет LPR разговора)
2. Ice: доступен только звонок
3. Touched: fill_discovery после LPR разговора
4. Touched: ограничения (нет заявки, КП, демо)
5. Demo_done: истекает через 60 дней
6. Demo_done: в пределах 60 дней
7. Ice: нельзя перепрыгнуть стадии
8. Interested: можно планировать демо

## 📈 Масштабирование до 10k компаний/день

### 1. Индексация
- Составные индексы для частых запросов
- Партиционирование таблицы events по дате

### 2. Event Sourcing
- Все изменения как события
- Возможность восстановления состояния
- Audit log из коробки

### 3. Минимизация блокировок
- Транзакции только для критических операций
- Оптимистичные блокировки через версионирование

### 4. Кэширование
- Redis для часто запрашиваемых данных
- Кэш условий переходов

## 🐛 Решение проблем

### "Container crm_mysql is unhealthy"
Это нормально при первом запуске. Подождите 1-2 минуты и обновите страницу.

### Порт занят
```bash
# Найти процесс на порту 8080
lsof -i :8080  # Mac/Linux
netstat -ano | findstr :8080  # Windows

# Изменить порт в docker-compose.yml
ports:
  - "9080:80"  # Использовать 9080 вместо 8080
```

### Сброс и чистый запуск
```bash
docker-compose down -v
docker-compose up -d
```
